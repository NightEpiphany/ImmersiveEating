# Example Resource Pack

Replace `modid:example_item` in `assets/food/definitions/example_item.json` with the real item ID before using this pack.

The model, animation, and texture use the shared prefix `example_item`. GeckoLib 5 resources are stored at `assets/food/geckolib/models/item/example_item.geo.json` and `assets/food/geckolib/animations/item/example_item.animation.json`. The sound file is `example_eating.ogg` and is mapped from the `eating` animation sound keyframe.
